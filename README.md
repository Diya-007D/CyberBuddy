1. Project Title

# 🛡️ CyberBuddy - Cyber Safety Assistant

CyberBuddy is a web-based cybersecurity awareness chatbot
designednto help users understand common online threats
and follow safe digital practices.

2. Project Overview

## Project Overview

CyberBuddy is a rule-based Cybersecurity chatbot developed
to promote awareness about online safety and cybersecurity.

It provides simple guidance on identifying cyber threats,
protecting personal information, securing online accounts,
and responding to suspicious online activities.

3. Objectives

## Objectives

- Promote cybersecurity awareness among users.
- Educate users about common online threats.
- Encourage safe password practices.
- Help users identify phishing and online scams.
- Provide basic guidance during cybersecurity incidents.
- promote responsible digital behaviour.

4. Features

## Features

- Interactive chabot interface.
- Rule-based automated responses.
- Suggested cybersecurity questions.
- Dark-themed user interface.
- Privacy-focused message handling.
- Emergency guidance for suspicious activities.
- Responsive web-design.

5. Cybersecurity Topics Covered.

## Cybersecurity Topics Covered

1. Phishing and Email scams
2. password Security and Multi-Factor Authentication.
3. Malware and Safe Downloads
4. Public Wi-Fi and VPN Safety
5. Social Engineering and Online Privacy

6. Emergency Assistance

## Emergency Assistance

CyberBuddy provides basic guidance for situations such as:

- Suspected online scams.
- Compromised or hacked accounts.
- Clicking suspicious links.
- Downloading suspicious files.
- Exposure of sensitive information.

For reporting cybercrime in India:
- Cybercrime portal: https://cybercrime.gov.in/
- Cybercrime Helpline: 1930

10. privacy and Security

- CyberBuddy does not require user registration.
- Users are advised not to share passwords,OTPs,
  PINs, or  banking information.
- Chat messages are not stored ina backend database.
- User messages are displayed using safe text handling.
- The chatbot provides general cybersecurity awareness
  and is not a replacement for professional incident response.
